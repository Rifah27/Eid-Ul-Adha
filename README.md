# Eid ul Adha — Luxury Greeting Card (React)

This is a small React app showcasing a premium Eid ul Adha digital greeting card with elegant Islamic aesthetics, CSS animations, and micro-interactions.

Features:
- Glassmorphism greeting card with Arabic calligraphy
- Animated crescent moon, floating lanterns, sparkling stars
- Typing blessing text, ripple button effect, fireworks canvas
- Music toggle, theme toggle (dark/light)
- Responsive and interactive (parallax, smooth transitions)

Quick start:

1. Install dependencies

```bash
npm install
```

2. Run dev server

```bash
npm run dev
```

3. Open the URL printed by Vite (usually http://localhost:5173)

Notes:
- This project uses Vite. Replace the placeholder audio URL in `src/components/MusicToggle.jsx` with a licensed music file if desired.
- To build for production: `npm run build` and `npm run preview` to test the production bundle.
